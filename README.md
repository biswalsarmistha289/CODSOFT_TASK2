# Calculator Application 🧮

## About the Project

This is a simple command-line Calculator application developed using Python as part of the CodSoft Python Programming Internship.

It allows users to perform basic arithmetic operations through a menu-driven interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Multiple calculations
- User-friendly menu-driven interface

## Technologies Used

- Python 3
- Visual Studio Code

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```

## Operations

1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Exit
